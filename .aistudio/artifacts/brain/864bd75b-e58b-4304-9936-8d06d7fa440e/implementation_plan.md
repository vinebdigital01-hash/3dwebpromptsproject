# APEX3D VAULT — $10,000/mo High-Converting 3D Prompt Sales Funnel (Awwwards Edition)

An ultra-luxury, high-converting 3D sales funnel combining motion aesthetics from **MotionSites.ai**, Apple VisionOS, and bespoke creative development. Features a 000→100 cinematic preloader, cursor spotlight reveal layer, live interactive Three.js prompt terminal, alternating bento grid with halftone textures, scroll-driven parallax explorations, interactive ROI upside calculator, and a full conversion checkout funnel with 1-click order bumps.

### 2. User Experience & Visual Design

#### Visual Identity & Design Tokens
- **Canvas Base**: Pitch obsidian (`#050508`), structural surfaces (`hsl(0, 0%, 8%)`), hairline strokes (`rgba(255, 255, 255, 0.08)`).
- **Accent Gradient**: `linear-gradient(90deg, #00FF9D 0%, #00F0FF 50%, #6366F1 100%)` and `linear-gradient(90deg, #89AACC 0%, #4E85BF 100%)` for logo rings, animated borders, and progress indicators.
- **Typography Pairings**: Refined display font pairing with tight geometric sans and monospace telemetry badges.
- **Halftone Texture Overlay**: Fine dot patterns on card hover states creating an authentic editorial look.

1. **Preloader Screen (000 → 100)**: Displays glowing counter, rotating action verbs, and glowing gradient loading bar before smoothly unveiling the interface.
2. **Fixed Floating Pill Navbar**: Angular logo with spinning gradient ring, navigation links, Web Audio sound toggle, and *"Unlock Access"* button.
3. **Cinematic Hero**: Ambient atmospheric visuals, cursor spotlight reveal layer, concentric telemetry arcs, cycling role copy, and dual CTAs with shine sweep.
4. **Live Prompt Terminal & 3D Playground**: Interactive code window with syntax highlighting, live token counter, copy button, and interactive Three.js 3D viewport.
5. **Vault Catalog Bento Grid**: Alternating column spans (7/5/5/7) featuring the 10 real bundle assets, filterable categories, and one-click FLIP prompt modal.
6. **Parallax Explorations Gallery & Infinite Marquee**: 3D floating visual showcases with parallax offset and smooth marquee banner.
7. **Agency ROI Profit Calculator**: Interactive project volume slider (1–30 client sites/yr) displaying real-time revenue differences.
8. **High-Converting Urgency Pricing**: Currency toggle (USD/EUR/INR), flash sale countdown (`04:22:15`), and 3 transparent tiers.
9. **Checkout Modal with One-Click Order Bump**: Direct purchase drawer with `$37 Midjourney & Spline 3D Shaders & Texture Pack` bump, total recalculation, and simulated order receipt.
10. **Wall of Love, 30-Day Guarantee & FAQ Accordion**: 6 agency reviews, luxury guarantee seal, and 6 collapsible questions.
11. **Cinematic Footer**: Social links, system status indicator, copyright, and contact channels.
